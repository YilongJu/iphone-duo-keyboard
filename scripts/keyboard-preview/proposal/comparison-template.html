Duo Keyboard Layout Proposal

Summary. The proposal makes each letter key 8% wider and 7% taller. It moves the letter rows 15 to 22 pt closer to the middle of the keyboard, and makes delete 15% wider.

  • The digit keys get 4% narrower. Return gets 18% narrower and the right shift 24% narrower.
  • The symbol keys right of the letters get 15% to 27% narrower. The ; and ' keys shrink the most, to 30 pt.
  • Every digit and symbol key keeps the same neighbouring letters, so the typing test cases and all scores so far stay valid.
  • Trade-off: caps lock (+8%) and the left shift (+10%) get wider. The letters move right only when the left keys grow or the right keys shrink.
  • Not settled: how the new sizes feel under your thumbs, above all on the ' key. Only a phone build shows that.

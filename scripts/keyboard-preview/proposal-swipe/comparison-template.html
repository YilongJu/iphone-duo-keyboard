Duo Slide Keys Proposal

Summary. On the folded phone, the return key gets 42% narrower, a comma key sits left of the period, and 18 keys type a second character when you slide up or down on them.

  1. Try the proposed keyboard below. Slide up or down on a key with a small gray character.
  2. Tell me to ship it, or name the keys to change.

Not settled: how often a fast tap counts as a slide by mistake. Only a phone build shows that.

Afterproposal, takes touches

A slide needs 18 pt of mostly vertical travel on a letter, about 40% of a key's height. A slide back to the start cancels it. The Q to P row stays plain, so the most used letters (E, T, O, I) do not have a slide.

Rules that stay the same

  • Shift and a letter still type the capital letter, never the second character.
  • In Chinese mode a slide types the Chinese form, such as ， 。 ？ ！.
  • A second character ends a word like any typed punctuation, so autocorrection and the space rules run as they do today.
  • A long press on a letter does nothing new, so a slow press never types a symbol.

Duo Keyboard preview

This page draws all three keyboard layers from Shared/keyboard-layout.json, the same file the iPhone app reads. Click a key to type into the text box. Hold a two-character key, or drag up or down on it, for the upper character. A layer key such as .?123 outlines the layer it opens.

The English corrections and the language model test of Duo Keyboard use one model file and one
framework, built on the work of other projects.
The repository does not hold either file. scripts/ci/fetch_language_model.sh downloads both
before a build, each from a fixed address, and checks each against a fixed SHA-256 value.

smollm2-lora-typed-seed1.Q4_K_M.gguf

  SmolLM2-135M by Hugging Face, https://huggingface.co/HuggingFaceTB/SmolLM2-135M at commit
  93efa2f097d58c2a74874c7e644dbc9b0cee75a2, an English language model with 135 million weights,
  under the Apache License, Version 2.0 (http://www.apache.org/licenses/LICENSE-2.0).

  Changes: this project trained a LoRA fine-tune of the model to re-rank the typing engine's
  readings (scripts/lm-finetune on the branch engine/lm-finetune), merged the fine-tune into the
  weights, converted the result to the GGUF file format of llama.cpp and stored its weights with
  about 4 bits each (the setting Q4_K_M). The file comes from the release
  lm-finetune-smollm2-lora-v1 of https://github.com/YilongJu/iphone-duo-keyboard:
  https://github.com/YilongJu/iphone-duo-keyboard/releases/download/lm-finetune-smollm2-lora-v1/smollm2-lora-typed-seed1.Q4_K_M.gguf
  105,453,504 bytes, SHA-256: fe82c0b617bdf19cf72b92148edbf9406c7547396ca7fac477485884431c07bb

  The training text comes from sentences of Tatoeba, https://tatoeba.org, under the Creative
  Commons Attribution 2.0 France licence (CC BY 2.0 FR,
  https://creativecommons.org/licenses/by/2.0/fr/). The project generated typing slips from
  those sentences.

llama.framework

  llama.cpp, https://github.com/ggml-org/llama.cpp, at release b4846, built by the azooKey
  project from its copy of the source, https://github.com/azooKey/llama.cpp. The file comes
  unchanged from
  https://github.com/azooKey/llama.cpp/releases/download/b4846/signed-llama.xcframework.zip
  SHA-256: db3b13169df8870375f212e6ac21194225f1c85f7911d595ab64c8c790068e0a
